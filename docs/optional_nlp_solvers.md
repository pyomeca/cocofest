# Solveurs optionnels du benchmark de pédalage

La documentation d’IPOPT, MadNLP, Fatrop, Alpaqa et ACADOS a été centralisée
dans le
[README du benchmark des solveurs de pédalage](cycling_solver_benchmark/README.md).

Ce README unique contient :

- les formulations mathématiques full et reduced;
- le modèle de fatigue et la fonction objectif;
- la collocation, les systèmes KKT, le scaling et l’ordre des variables;
- les stratégies de warm-start et de compilation persistante;
- l’organisation GitHub Actions;
- les résultats Linux et les expériences historiques;
- les limites connues d’Alpaqa et d’ACADOS;
- les commandes de reproduction et la liste des artefacts.
